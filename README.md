# Telegram Price Bot

a simple Telegram bot Built with Python and pyTelegramBotAPI

## Features
- Responds to /start command
- Echos back any message


## How to Run
1.install dependencies: 'pip install pyTelegramBotAPI
2.Replace  the tocken in 'bot.py'
3.Run: 'python bot.py'
